# AV Resume

David Robertson's professional resume site — an IATSE Local 8 video & lighting technician based in Philadelphia, PA. A single-page, print-and-web-friendly resume covering experience, core skills, and notable credits (The Mann Center, NASA/Kennedy Space Center, national touring and broadcast events).

## What's here

| Path | What it is |
|---|---|
| `index.html` | The entire site — resume content, styles, and interaction logic in one self-contained file |
| `favicon.svg` | Site favicon ("AV" monogram) |
| `LICENSE` | All-rights-reserved license |

## Features

- Light/dark theme toggle (defaults to light mode)
- Mobile-responsive layout
- "Download Resume PDF" button that triggers the browser's print dialog for a clean PDF export
- Mailto link pre-filled with a production inquiry template

## How to view it

Open `index.html` directly in a browser — no build step, server, or dependencies required.
